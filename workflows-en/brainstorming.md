# /brainstorming Workflow

Start the brainstorming process when user types `/brainstorming`.

## Trigger Conditions
- User types `/brainstorming`
- Before starting a new feature or project

## Execution Steps

### 1. Understand Requirements
Ask the user:
- "What functionality do you want to implement?"
- "What problem does this feature solve?"
- "Are there reference implementations?"

### 2. Clarify Details
Ask key questions:
- What is the core value?
- What are the constraints?
- What is the expected timeline?
- What are the success criteria?

### 3. Explore Solutions
- Propose 2-3 viable solutions
- Analyze pros and cons of each
- Recommend the best solution with rationale

### 4. Present in Sections
Break design into small chunks:
- Each part no more than 5 mins reading time
- Wait for user confirmation before continuing
- Record feedback and decisions

### 5. Output Design Document
Generate `implementation_plan.md` containing:
- Problem description
- Selected solution
- Implementation steps
- Acceptance criteria

## Completion Checklist
- [ ] Requirements clarified
- [ ] Solution selected
- [ ] Design document generated
- [ ] User confirmed
