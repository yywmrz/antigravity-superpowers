# Development Workflow

## Use Cases
- Starting development of a new feature
- Implementing a new user requirement

## Process

// turbo-all

### 1. Requirements Clarification
Use `brainstorming` skill for requirements clarification:
- Understand what the user really wants
- Ask clarifying questions
- Explore alternative solutions
- Output design document for user confirmation

### 2. Create Plan
Use `writing-plans` skill to create implementation plan:
- Break work into 2-5 minute tasks
- Each task includes precise file paths and code
- Mark verification steps
- Request user approval for plan

### 3. Test-Driven Implementation
Use `test-driven-development` skill to write code:
- Write failing test first (RED)
- Write minimal code to pass (GREEN)
- Refactor code (REFACTOR)
- Commit changes

### 4. Code Review
Use `code-review` skill for self-review:
- Check correctness
- Check edge cases
- Check code style
- Check performance issues

### 5. Final Verification
Use `verification-before-completion` skill to verify:
- Functional verification
- Regression verification
- Integration verification
- Update documentation

## Checkpoints
- [ ] Design document approved
- [ ] Implementation plan approved
- [ ] All tests passing
- [ ] Code review passed
- [ ] Final verification passed
